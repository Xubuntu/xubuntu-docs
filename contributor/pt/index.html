Bem-vindo!

A documentação é a referência para todos os contribuidores do Xubuntu. Os capítulos desta documentação fornecem informação sobre os processos de desenvolvimento - tanto social como técnico - que os contribuidores do Xubuntu utilizam como linhas orientadoras no seu trabalho.

Existem dois apêndices principais para esta documentação:

  • Apêndice A, Documento estratégico, a qual é a linha orientadora principal no desenvolvimento do Xubuntu.

  • Apêndice B, Referência Comum, a qual descreve muitas das tarefas técnicas que os programadores do Xubuntu precisam de utilizar continuamente.

Esta documentação é escrita assumindo que o utilizados conhece o funcionamento básico do Xubuntu. Por exemplo, espera-se que o leitor saiba como trabalhar com um terminal e compreenda quando necessita de o utilizar, sem uma menção explícita.
