Documentação da manutenção da página Web do Xubuntu

Lançamentos

A página Web do Xubuntu rastreia lançamentos com uma taxonomia personalizada do WordPress. Os termos da versão podem ser anexados a praticamente qualquer tipo de conteúdo utilizado na página. As informações sobre o termo de lançamento e o conteúdo anexado são utilizados para automatizar a criação de algum conteúdo na página Web, incluindo, mas não necessariamente limitado: às páginas de lançamento,, à página de Transferências, à Ajuda e Suporte e à página na Imprensa.

Para editar as informações genéricas de cada versão (nome de código, data da versão, data de fim de vida, ligações para transferências Torrent, documentação on-line e mudança de versão), vá a Posts – Lançamentos.

Para anexar algum conteúdo a um lançamento, selecione o(s) lançamento(s) pretendido(s) na página de edição de conteúdo.

Os códigos seguintes são utilizados para apresentar informação de lançamento agregada (substitua xx-xx pela versão desejada):

  • [torrents release=xx-xx] para apresentar ligações de transferência Torrent

  • [mirrors release=xx-xx] para apresentar a lista de ligações com informação adicional disponível

  • [press release=xx-xx] para apresentar todas as ligações de imprensa associadas ao lançamento e[press] para apresentar o arquivo de imprensa

  • [documentation_links] para apresentar uma lista com ligações para a documentação on-line para todas as versões lançadas e suportadas

A página de lançamento das versões utiliza uma página modelo com o mesmo nome; o modelo lista todas as versões lançadas e suportadas com uma pequena descrição. As páginas de lançamento são criadas automaticamente.

Ligações de lançamento

Para adicionar ligações de imprensa (e outras ligações oficiais específicas do lançamento com exceção das ligações de transferência do Torrent e ligações da documentação on-line), vá a Ligações de Lançamento. Uma vez adicionadas à base de dados, as ligações irão aparecer nos locais apropriados automaticamente.

Opções de transferência

As listas de ligações para transferência são criadas automaticamente a partir de modelos de URL guardados na base de dados. Para gerir os espelhos de listas de transferências, vá a DL Mirrors. É possível ativar ou desativar os espelhos de transferência nas páginas de edição (respetivamente visíveis e ocultas no frontend). É igualmente possível definir que ligações para transferência são apresentadas na listagem por defeito; defina um espelho como um espelho para transferência principal caso pretenda que seja visível diretamente.
