Notas sobre a documentação dos contribuidores

Por diversos motivos, a documentação dos contribuidores é mais estruturalmente complexa do que a documentação do utilizador. Preste especial atenção ao seguinte quando trabalhar com a subequipa de documentação:

  • Caso pretenda criar um parágrafo introdutório para ser apresentado na página principal da subequipa, não o coloque simplesmente dentro de um elemento <section>. Caso contrário. será colocado num ficheiro HTML separado.

  • Caso pretenda que uma subsecção de uma secção seja visível na Tabela de Conteúdos, adicione o atributo <role="toc"> ao elemento <section>. Por exemplo, consulte os ficheiros qa-*.

  • As secções são cortadas no primeiro nível; tal significa que todos os ascendentes diretos <section> dos elementos <chapter> serão cortados em ficheiros HTML separados. Caso pretenda prevenir isto (por exemplo, se o seu capítulo for muito curto), insira o <?dbhtml stop-chunking?> após o elemento <title> do seu capítulo.Note que executar esta ação não impedirá que a Tabela de Conteúdos seja impressa com todas as secções. Pode utilizar o elemento <simplesect> novamente para ocultar secções da Tabela de Conteúdos. Caso o faça, certifique-se de que não insere quaisquer elementos após o elemento <simplesect> no seu capítulo, uma vez que tal invalidará o documento.
