Infraestrutura de Testes

Preparação dos testes

A fim de testar o Xubuntu com sucesso, irá necessitar de, pelo menos, 4 coisas: uma conta no Launchpad, uma subscrição de lista de correio, uma imagem e algo para testar nela. Esta página fornece-lhe a informação básica necessária para isso, entre outros.

Contactos

É necessário possuir uma conta no Launchpad a fim de se unir à(s) equipas necessárias e iniciar sessão nos 2 trackers do Controlo de Qualidade.

Utilizamos uma lista de correio para detalhar o que pretendemos testar durante um ciclo e para solicitar novos testes. Esta lista também é utilizada pela equipa para discussões acerca do desenvolvimento do Xubuntu. Terá de se unir à lista Xubuntu Devel Correio.

Embora não seja estritamente necessário, utilizamos extensivamente o IRC, pelo que possuir uma conta passível de ser utilizada para aceder ao canal principal #xubuntu-devel poderá ajuda-lo. Alternativamente, é possível aceder ao canal através do separado IRC no separador desenvolvimento do Xubuntu.

Unir-se à equipa de testes Launchpad do Xubuntu

Considere adicionar os seus detalhes à pagina Equipamento. Podemos utilizar estes dados para solicitar testes específicos a testadores específicos.

Obter a ISO

As ISOs podem ser obtidas através de alguns métodos. O método mais simples é visitar o tracker ISO. Siga os casos de testes através do nome de código do lançamento para o grupo de testes do Xubuntu. Em seguida, escolha entre 64 ou 32 bits. As ligações para transferência encontram-se disponíveis lá.

Ao testar de forma mais regular, pode considerar (especialmente se a largura de banda for um problema) utilizar a ligação zsync mais apropriada. Isto irá detetar as diferenças entre a sua cópia local e a cópia atual.

Metodologia de testes

Agora que configurou os seus contacto(s) básico(s) e possui a sua ISO, encontra-se em posição de a testar.

Existem dois métodos principais para testar as ISOs:

  • Utilizar uma máquina virtual permite-lhe continuar a utilizar uma distribuição normal durante os testes às ISOs. Pode instalar uma máquina virtual utilizando a ISO que transferiu.

  • Instale a ISO num equipamento onde essa possibilidade se encontra disponível. Tal torna-se particularmente importante no final do ciclo de desenvolvimento. Será necessário que a ISO seja armazenada num meio de arranque. Um membro da equipa da página Web do Xubuntu detalha um método simples para preparar um um meio USB de arranque através do Discos do GNOME.

Embora seja possível utilizar o VirtualBox, experiências anteriores demonstraram que problemas encontrados durante os testes no VirtualBox são difíceis de replicar noutros locais. Poderá desejar utilizar o KVM. Os membros da Equipa de Controlo de Qualidade do Xubuntu possuem experiência com a utilizaçãodisso para testes e podem ajudar.

Reportar o resultado

Utilizamos dois trackers de Controlo de Qualidade.

  • O tracker de ISO mencionado acima para quaisquer testes realizados com uma ISO sejam de instalação ou de atualização.

  • O tracker Pacote, que é utilizado quando estamos a testar aplicações durante um ciclo.

Esses trackers formam a espinha dorsal do que somos capazes de ganhar a partir dos seus testes. É importante que reporte os seus resultados.
