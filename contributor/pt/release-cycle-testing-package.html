Testes aos pacotes

Quando se encontrarem a ser utilizados, a equipa de Controlo de Qualidade agendará as sprints de teste aos pacotes para que ocorram durante o ciclo entre os testes de milestone para se certificar de que as aplicações incluídas no Xubuntu tenham passado por uma quantidade suficiente de testes.

Independentemente de os pacotes serem testados durante o ciclo de desenvolvimento, devem ser efetuados testes adicionais para uma nova aplicações por defeito que seja incluída no próximo lançamento do Xubuntu, quando uma aplicação sofre atualizações significativas a meio do ciclo ou quando os programadores pedem testes específicos a uma atualização específica de uma aplicação.

Os pedidos de sprints de testes a pacotes serão enviados conforme necessário.
