Introdução à presença Web do Xubuntu

Xubuntu.org

A página Web é a principal fonte de informação para os utilizadores. O conteúdo na página Web deve ser facilmente compreensível.

A página Web utiliza o WordPress instalado num servidor da Canonical IS. O conteúdo da página Web é controlado e administrado pela equipa da página web do Xubuntu. A equipa da página Web pode enviar informação para a Canonical IS caso haja algum problema. Os erros relacionados com a página Web podem ser inseridos no Launchpad, através do link: erros da página Web do xubuntu.

O código-fonte da página Web está disponível em lp:xubuntu-website(o tema) e lp:xubuntu-website/plugins(os plugins).

Wiki do Xubuntu

A wiki do Xubuntu é utilizada para algumas comunicações entre os programadores e funciona como um arquivo de roadmaps e especificações de lançamentos antigos.
