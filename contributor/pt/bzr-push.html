Efetuar push para as ramificações do Bzr

Quando tiver efetuado alterações e pretender envia-las para um ramo remoto, execute o seguinte comando no ramo local:

  • Para renomear ou mover ficheiros, execute.bzr mv ANTIGO NOVO. Isto é útil para dar significado ao diff resultante, além de também funcionar à posteriori.

  • Caso tenha adicionado ficheiros, execute bzr add . no ramo da raiz. Isto permite começar a monitorizar quaisquer ficheiros no ramo que sejam atualmente desconhecidos.

  • Caso tenha removido ficheiros, execute bzr remove. Na maior parte dos casos, tal permite parar de monitorizar automaticamente ficheiros que já não se encontram no ramo.

  • Para verificar o estado de um ramo, execute bzr status.

  • Efetue commit das suas alterações através da execução de bzr commit. Isto abrirá um editor de texto para inserção da mensagem associada ao commit.

  • Após a execução de um ou mais commits, execute bzr push LOCALIZAÇÃO para enviar as suas alterações para um ramo remoto.

A mensagem associada a um commit deve resumir todas as alterações efetuadas após o commit anterior. Pode especifica-la diretamente através de -m MENSAGEM e associar um relatório de erro ao commit através de --fixes lp:BUGNO.

Quando se encontrar a trabalhar num ramo e a fazer diversas alterações não inter-relacionadas, é recomendável que faça vários commits. Isto ajuda a manter o registo de commits limpo e facilita a deteção de quaisquer erros que determinadas alterações tenham introduzido.

Quando enviar dados para um ramo remoto pela primeira vez, terá de especificar a localização do ramo. Na maior parte dos casos, esta segue o formato lp:~username/projectname/branchname. Isto envia o seu código para um ramo remoto pessoal. Em envios subsequentes, pode omitir a localização do ramo, uma vez que o Bzr guarda a localização do envio anterior na configuração do ramo local.
