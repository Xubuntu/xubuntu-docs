Enviar informação para os repositórios Git

Quando tiver efetuado alterações e pretender envia-las para um repositório remoto, execute o seguinte comando no ramo local:

  • Para renomear ou mover ficheiros, execute.git mv ANTIGO NOVO. Isto é útil para dar significado ao diff resultante, enquanto o Git o descobre automaticamente.

  • Para remover ficheiros, execute git rm FICHEIRO. Isto também para a monitorização de ficheiros específicos, ao mesmo tempo que é redundante se todas as alterações forem organizadas mais tarde.

  • Caso tenha adicionado ficheiros, execute git add . no ramo da raiz. Isto permite começar a monitorizar quaisquer ficheiros no ramo que sejam atualmente desconhecidos, além de permitir organizar quaisquer alterações.

  • Para verificar o estado de um ramo, execute git status.

  • Efetue commit das suas alterações através do comando git commit -a. Isto organiza quaisquer alterações e abrirá um editor de texto para inserção da mensagem associada ao commit.

  • Após a execução de um ou mais commits, execute git push LOCALIZAÇÃO RAMO para enviar as suas alterações para um repositório remoto.

A mensagem associada a um commit deve resumir todas as alterações efetuadas após o commit anterior Pode especifica-la diretamente através de -m MENSAGEM.
