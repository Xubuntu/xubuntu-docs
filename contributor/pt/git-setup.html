Configurar o Git

Para configurar o Git, execute os seguintes passos:

  • Para se certificar de que o Git se encontra instalado no seu sistema, execute o seguinte comando:

    sudo apt-get install git

  • Para configurar a sua informação pessoal a ser utilizada pelo Git, execute:

    git config --global user.name "John Doe"

    git config --global user.email "john.doe@gmail.com"
