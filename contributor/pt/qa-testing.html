Testes de pacotes e de ISO

ISOs

Normalmente, as ligações para ISOs específicas para testes diários ou de milestone podem ser encontradas em Tracker ISO. Existe uma ligação para o atual desenvolvimento da ISO diária. Tal pode ser útil, especialmente durante a configuração de métodos de transferência da sua ISO de teste, tal como zsync.

É possível encontrar o último estado de instalação e inicialização conhecido das nossas ISOs em Estado do Controlo de Qualidade do tracker de estado de desenvolvimento

Testes Exploratórios

Além de testar as imagens e o software com ações de teste predefinidas (testes estáticos), os membros da comunidade também podem participar em testes exploratórios.

Basicamente, os testes exploratórios consistem em executar a versão de desenvolvimento e executar as suas tarefas diárias com o sistema e, finalmente, reportar erros quando os encontrar. Isso permite que o Xubuntu obtenha uma abrangência de testes muito maior do que é possível com testes pré-definidos.

Uma maneira útil de lidar com isso é através de arranques duplos (ou múltiplos). Através do arranque duplo (ou múltiplo), pode garantir de que consegue aceder sempre durante os testes ao sistema de desenvolvimento. Desta forma, pode trabalhar tanto na versão de desenvolvimento como é prático - enquanto procura erros e regressões na versão de desenvolvimento.

Quando em arranque duplo (ou múltiplo), pode ser útil instalar o carregador de arranque em partições específicas. Podem ser encontradas informações simples acerca deste assunto em Localização das Partições Manuais e do Carregador de Arranque.

As questões de interesse para a equipa de desenvolvimento incluem, além de problemas reportados normalmente, erros de usabilidade, ícones ausentes ou funcionalidades inconsistentes.

Utilização de PPAs de Desenvolvimento

Existem 3 PPAs que utilizamos regularmente nos testes aos pacotes. Estes são:

  • Temas Shimmer para compilações diárias dos projetos do Projeto Shimmer

  • compilações diárias do Xubuntu para compilações diárias do Git e do Bzr para pacotes relacionados com o Xubuntu e/ou o Xfce4

  • Controlo de Qualidade Experimental do Xubuntu para pacotes e versões de pacotes que se encontram a ser preparados para integração no Xubuntu, enviados para conveniência das pessoas que testam estas novas versões de pacotes e funcionalidades num ambiente estável

  • Organização do Controlo de Qualidade do Xubuntu para testes a pacotes a versões previamente lançadas e atuais do Xubuntu

Por vezes, a equipa de desenvolvimento utiliza outros PPAs para testar pacotes específicos. Serão divulgados aos testadores detalhes acerca dos mesmos sempre que apropriado

A instalação a partir destes PPAs significa estará a utilizar e a testar pacotes sobre os quais os programadores se encontram a trabalhar. Tal significa que é possível encontrar regressões que não estarão presentes aquando do lançamento.

Remover um PPA em utilização. Utilizar o comando ppa-purge fará com que o apt desative uma lista de fontes de PPA e altere os pacotes afetados novamente para as suas versões por defeito.

  • Execute sudo apt-get install ppa-purge

  • Execute sudo ppa-purge ppa:ppaname

Pode ser problemático reportar erros com PPAs; por favor, consulte mais informações acerca do reporte de erros com PPAs em Reportar erros nos PPAs.

Testes Estáticos

Testar as versões de desenvolvimento do Xubuntu e dos pacotes ajuda a manter a qualidade diária. Caso possua recursos de hardware adequados ou seja capaz de executar os testes num ambiente virtualizado, pode ajudar.

Consulte a lista de correio de desenvolvimento quando se aproximar o início de um ciclo, dado que é nessa altura que a decisão acerca da(s) semana(s) de testes em que participaremos será discutida.

Durante as semanas de teste a ISO continuará a ser desenvolvida, a equipa de Controlo de Qualidade do Xubuntu consultará os relatórios do tracker e informará os testadores de problemas anotados em dias anteriores. Serão registadas observações no tracker apropriado Páginas de Estado do Controlo de Qualidade.

Semanas de Testas

Os testes fixos da ISO só serão realizados na Beta Final. Durante essa milestone são úteis nos 2 dias anteriores ao lançamento para que o seguinte tenha acontecido.

  • Sessão Live: Arranque com a imagem e garanta que os testes básicos às aplicações (abrir, fechar, salvar etc.) são aprovados.

  • Os testes de instalação devem ser obrigatoriamente aprovados. Estes testam apenas a instalação.

Testes Diários

A importância dos testes às imagens diárias prendem-se essencialmente em garantir que não ocorrem regressões no arranque e/ou instalação. Quando aparecerem, caso seja capaz de arrancar com uma imagem de outra distribuição, tal ajuda a provar a existência de um problema global ou local no Xubuntu. Em caso de dúvida, consulte a equipa do Xubuntu, preferencialmente através do IRC.

  • Sessão Live: Arranque com a imagem e garanta que os testes básicos às aplicações (abrir, fechar, salvar etc.) são aprovados.

  • Os testes de instalação devem ser obrigatoriamente aprovados. Estes testam apenas a instalação.

Testes de Atualização

A cerca de meio caminho de qualquer ciclo de desenvolvimento (por volta das milestone beta) precisamos de testar atualizações de versões anteriores para a nova versão de desenvolvimento. . Quando a versão de desenvolvimento for definida para ser o próximo lançamento LTS, teremos necessidade de testar ambos os caminhos de atualização: LTS para LTS e regular para LTS.

O tracker de ISO possui uma secção para testes de atualização que não se altera diariamente, mas que executa de sexta-feira a sexta-feira. Durante estes testes, é preferível que a imagem utilizada nos testes seja a da primeira sexta-feira, exceto quando existam erros reportados e correções emitidas.

  • Atualização: testada através do gestor de atualizações

  • Atualização (imagem): testada através da imagem diária

Testes de Pacotes

Para lançamentos onde utilizamos o tracker de Pacotes, serão feitas solicitações de testes a pacotes através da lista de correio xubuntu-devel conforme necessário. Estas solicitações podem partir do Controlo de Qualidade ou dos programadores.

Será enviado um agendamento de testes planeados para a lista do correio Xubuntu devel perto da data de início do ciclo. São enviados lembretes de necessidade de testes aos próximos pacote para a lista do correio Xubuntu devel conforme necessário. Pedido de teste específico ao programador são enviados à medida que ficarem disponíveis; habitualmente, estes pacotes são os que podem ser encontrados num dos nossos PPAs.
