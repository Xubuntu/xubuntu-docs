Resolução de problemas de rede

Resolução de problemas de rede

Antes de tentar qualquer resolução de problemas, certifique-se de que as ligações de rede se encontram ativas:

  • Clique o ícone NetworkManager presente na área de notificação

  • Selecione Ativar a Rede

  • SelecioneAtivar Wi-Fi

Se a ligação de rede ainda assim não funcionar:

  • Para ligações com fio (Ethernet), consulte Resolução de problemas gerais

  • Para ligações sem fios, consulte Resolução de problemas gerais e Resolução de problemas com redes sem fios

  • Caso os problemas de ligação de rede persistam, consulte Resolução de problemas avançada

Resolução de problemas gerais

Caso a ligação de rede não se encontre a funcionar corretamente, existem algumas ferramentas que podem ser utilizadas ​​para ajudar a diagnosticar o problema.

Obter informações sobre a ligação atual

Para obter informações sobre a sua ligação de rede e dispositivos de rede, tem duas opções:

  • Através do NetworkManager

    • Clique no ícone NetworkManager

    • Selecione Informação de ligação. Caso esta opção se encontre desativada, é possível é possível que não existam ligações ativas. Tente utilizar o comando ip para saber mais.

    • Cada ligação ativa terá o seu próprio separador onde pode encontrar informações relevantes sobre a ligação

  • Utilizar o ip

    • Abra o terminal ( → Acessórios → Emulador de terminal), introduza o comando ip address e clique na tecla Enter.

    • O ip irá apresentar-lhe informações detalhadas acerca da sua ligação, incluindo nomes lógicos ou de ligações (p. ex., epm3s0) na primeira linha, o endereço IP na linha inet e o endereço MAC do seu dispositivo na linha link/ether

Verificar se uma ligação se encontra a funcionar corretamente

Um método fidedigno para verificar se a ligação se encontra a funcionar corretamente é efetuar ping a outro computador na rede ou na Internet.

Para verificar se o seu computador se encontra ligado à internet, abra o terminal ( → Acessórios → Emulador de terminal), introduza o comandoping -c 3 www.xubuntu.org e clique na tecla Enter.

O computador irá então tentar contactar www.xubuntu.org três vezes e apresentará os resultados. As estatísticas de ping mostram o número de pacotes transmitidos, quantos pacotes foram recebidos, a percentagem de perda de pacotes, e o tempo total gasto.

  • 0% de perda de pacotes indica que o computador se encontra ligado à Internet

  • Maior do que 0% mas inferior a 100% de perda de pacotes indica que o computador possui uma má ligação à Internet ou um sinal de rede sem fios fraco

  • 100% de perda de pacotes indica que o computador possui uma má ligação, ou se encontra ligado a um ponto de acesso ou router que não se encontra ligado à Internet

Caso obtenha uma mensagem de erro a indicar “www.xubuntu.org não pode ser encontrado” ou “nome ou serviço desconhecido”, é provável que o seu computador não se encontre ligado à internet ou não consiga alcançar o servidor de Sistema de Nomes de Domínio (DNS).

Resolução de problemas com redes sem fios

Esta secção aborda alguns problemas comuns relacionado com o suporte a redes sem fios. Existem muito mais informações disponíveis na Wiki de Ajuda da Comunidade.

Por favor tenha em atenção que as etapas neste guia de resolução são concebidas para serem realizadas pela ordem indicada, a menos que seja apontado para uma subsecção diferente.

Verificar que o dispositivo se encontra ligado

Muitos dispositivos de rede sem fios podem ser ligados ou desligados. Verifique se existem um interruptor de hardware ou uma tecla de função de teclado para ligar o dispositivo sem fios.

Caso o dispositivo se encontre ligado, continue para o próximo tópico.

Verifique se o dispositivo é reconhecido

Abra o terminal ( → Acessórios → Emulador de terminal), introduza o comando sudo lshw -C network, e clique na tecla Enter. Verá algum texto de saída, incluindo as palavras CLAIMED, UNCLAIMED, ENABLED or DISABLED.

  • CLAIMED indica que um controlador se encontra carregado, mas não está a funcionar. Continue para Utilizar os controladores de redes sem fios do Windows.

  • UNCLAIMED indica que não existe um controlador carregado. Continue para Utilizar os controladores de redes sem fios do Windows.

  • ATIVADO indica que o controlador se encontra instalado e a funcionar. Continue para a secção Verificação da ligação com o router.

  • DESATIVADO indica que o controlador se encontra instalado, mas desativado. Continue para Verificar que o dispositivo se encontra ligado.

Utilizar os controladores de redes sem fios do Windows

O Xubuntu suporta um sistema conhecido como NDISWrapper. Isto permite a utilização de um controlador de dispositivos sem fios do Windows no Xubuntu. Para começar a utilizar o NDISWrapper:

  • Obtenha o controlador do Windows para o seu dispositivo de rede e localize o ficheiro que termina com .inf

  • Instale o pacote ndisgtk

  • Vá para o → Gestor de definições → Controladores sem fios do Windows

  • Selecione Instalar novo controlador

  • Escolha a localização do seu ficheiro .inf do Windows e clique em Instalar

  • Clique em OK

Verificação da ligação com o router

Abra o terminal ( → Acessórios → Emulador de terminal), introduza o comando iwconfig e clique na tecla Enter.

Caso o ESSID para o seu router seja apresentado, poderá existir um problema com o suporte a ACPI. Arranque o Xubuntu com a opção pci=noacpi.

Resolução de problemas avançada

Os seguintes métodos de resolução de problemas são um pouco mais técnicos. Por favor tente estes métodos apenas se os métodos anteriores falharem.

Verificação de atribuição de IP

Abra o terminal ( → Acessórios → Emulador de terminal), introduza o comando ip address e clique na tecla Enter . Caso seja apresentado um endereço IP, siga para Verificação de Servidores de Nomes de Domínio (DNS).

No terminal, execute o seguinte comando, substituindo enp3s0pelo nome da ligação apresentado na saída do comando ip address : sudo dhclient enp3s0

  • Caso receba uma mensagem que diz vinculado a xxx.xxx.xxx.xxx continue para Verificação de Servidores de Nomes de Domínio (DNS)

  • Caso contrário, reinicie o sistema

Verificação de Servidores de Nomes de Domínio (DNS)

Abra o terminal ( → Acessórios → Emulador de terminal), introduza o comando nmcli device show e clique na tecla Enter. Procure entradas sob IP4.DNS

Para verificar se os DNS listados funcionam., abra o terminal ( → Acessórios → Emulador de terminal), introduza o comandodig xubuntu.org e clique na tecla Enter. Caso veja a palavra NOERROR na secção de cabeçalho da saída, o seu DNS encontra-se em funcionamento.

Caso não existam definições de DNS listadas, contacte o seu fornecedor de serviço de internet (ISP) e informe-se acerca dos seus servidor de nomes de domínio primário e secundário.
