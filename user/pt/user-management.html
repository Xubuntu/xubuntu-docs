Por questões de segurança, as tarefas administrativas no Xubuntu só podem ser executadas por utilizadores com privilégios especiais. A primeira conta de utilizador criada durante a instalação será capaz de executar tarefas administrativas por defeito.

Ao executar uma aplicação que necessita de privilégios de administrador, ser-lhe-á solicitada a introdução da sua palavra-passe. Isto ajuda a proteger o seu sistema de atividade maliciosa e diminui a hipótese de alterar acidentalmente a forma como o seu sistema funciona.

Sempre que introduzir a sua palavra-passe numa sessão do terminal, esta será recordada durante 15 minutos, para que não tenha de a introduzir novamente.

Os utilizadores devem ser um membro do grupo 'sudo' de modo a realizarem operações administrativas. Informações sobre como alterar os grupos podem ser encontrados abaixo.

Utilizadores e grupos

Aquando da instalação do Xubuntu, apenas é criada uma conta de utilizador. Caso vários utilizadores usem o computador, é altamente recomendável criar contas de utilizador separadas para cada um. Isto permite que os utilizadores tenham as suas permissões de acesso, ficheiros e definições individuais.

Para alterar os utilizadores ou grupos do seu sistema, navegue para → Gestor de definições → Utilizadores e grupos.

É necessário ter direitos administrativos para fazer alterações em utilizadores e grupos.

Gerir utilizadores

Para adicionar um novo utilizador:

  • Clique no botão Adicionar

  • Introduza a sua palavra-passe

  • Preencha os campos Nome e Nome de Utilizador

  • Clique o botão OK

Se quiser dar a um utilizador direitos administrativos para o sistema:

  • Selecione o utilizador cujo tipo de conta deseja alterar e pressione o botão Alterar...

  • Introduza a sua palavra-passe caso esta seja solicitada

  • Selecione a opção Administrador (ou selecione Utilizador para reverter)

  • Pressione OK para aplicar as alterações selecionadas

Para um controlo de acessos mais fino, clique no botão Definições Avançadas da janela Definições do utilizador, introduza a sua palavra-passe, clique no separador Privilégios de Utilizador e selecione ou remova a seleção das opções pretendidas.

Para remover um utilizador do sistema, selecione o utilizador que deseja excluir e clique no botão Apagar.

Gerir Grupos

Para adicionar um novo grupo:

  • Clique o botão Gerir Grupos

  • Clique no botão Adicionar

  • Introduza a sua palavra-passe

  • Escolha um nome para o novo grupo e, se quiser, mude o valor predefinido para o Group ID

  • Neste momento, tem a opção de selecionar os Membros do Grupo na lista

  • Clique o botão OK

Para remover um grupo do sistema, clique no botão Gerir Grupos, selecione o grupo que deseja excluir e clique no botão Apagar.

Personalizar a sua informação pessoal

O Mugshot é um utilitário leve de configuração de utilizador que permite definir facilmente a imagem do perfil de utilizador e detalhes do seu perfil de utilizador em todas as aplicações suportadas.

Para executar oMugshot navegue para o → Gestor de definições → Sobre Mim.

Para alterar sua imagem de perfil, clique no botão da imagem à esquerda da GUI, selecione uma das opções apresentadas e siga as instruções.

O Mugshot requer a instalação do pacotegstreamer1.0-tools para utilizar a funcionalidade Capturar da câmara....

Preencha os campos de texto com os dados pessoais necessários e clique Aplicar. Ao aplicar estes detalhes com o Pidgin e/ou o LibreOffice instalados, será solicitado a atualizar as suas definições também.

Se os dados pessoais inseridos nos campos de texto Nome e Apelido diferirem dos valores existentes no ficheiro /etc/passwd, será solicitado a inserir a sua senha como uma medida de segurança para evitar atualizações indesejadas às suas informações pessoais.
