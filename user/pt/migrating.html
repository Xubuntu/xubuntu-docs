Aplicações Windows no Linux

É possível executar aplicações do Windows no Xubuntu. Três opções populares são:

  • Wine (wine), o emulador de Windows. O Wine permite a execução de aplicações sem a necessidade de instalar um sistema operativo Windows. Consulte o Wine AppDB para descobrir as aplicações que funcionarão no Wine e a Documentação do Wine para perguntas frequentes e suporte ao utilizador.

  • PlayOnLinux é uma camada de apresentação para o Wine fácil de utilizar, que facilita a instalação de aplicações populares do Windows.

  • VirtualBox, virtualização de software. Pode instalar um sistema operativo Windows, juntamente com qualquer aplicação numa máquina virtual gerida pelo VirtualBox. Para ler mais sobre o VirtualBox e a virtualização, consulte o site Documentação do utilizador final VirtualBox.

Quer o Wine quer o VirtualBox se encontram disponíveis nos repositórios de software.

Redes Windows no Linux

O acesso a partilhas de rede Windows no Xubuntu pode ser efetuado facilmente através de:

  • → Acessórios → Gestor de ficheiros, onde pode navegar partilhas públicas visíveis se clicar no item Rede presente na barra lateral. Como alternativa. pode navegar para um sistema de ficheiros remoto se for a Ir → Abrir localização... e introduzir smb://nomedocomputador/nomedapartilha.

  • → Sistema → Gigolo, o qual lhe permite guardar marcadores e gerir sistemas de ficheiros remotos. Para se ligar, clique no primeiro botão da barra de ferramentas. Selecione Partilha do Windows do Tipo de serviço, e introduza os detalhes da partilha remota.

Caso algumas opções nãos e encontram disponíveis ou não funcionem, certifique-se de que ogvfs-backends se encontra instalado.
