O seu computador é constituído por um certo número de dispositivos ligados entre si que são coletivamente conhecidos como hardware.

Normalmente, o Xubuntu configura o hardware automaticamente, mas pode haver ocasiões em que será necessário fazer alterações nas configurações de hardware manualmente. Esta secção fornece informações sobre as ferramentas que podem ser utilizadas para configurar o hardware.

Controladores restritos

Porque é que alguns controladores são restritos?

Os controladores restritos são controladores para o seu hardware que não se encontram disponíveis gratuitamente ou não são de código aberto.

A maioria dos dispositivos (hardware) ligados ao seu computador deverá funcionar corretamente no Xubuntu. Estes dispositivos provavelmente possuem controladores não restritos, o que significa que os controladores podem ser modificados pelos programadores do Xubuntu e os seus problemas podem ser corrigidos.

Alguns dispositivos não possuem controladores não restritos, normalmente porque o fabricante do hardware não lançou detalhes que tornariam possível a criação de tal controlador. Estes dispositivos podem ter funcionalidades limitadas ou podem não funcionar de todo.

Ativação de controladores restritos

Caso um controlador restrito se encontre disponível para um determinado dispositivo, pode ser instalado a fim de permitir que o dispositivo funcione corretamente, ou para adicionar novos recursos. Por exemplo, a instalação de um controlador restrito para determinadas placas gráficas pode permitir a utilização de efeitos visuais mais avançados.

Alguns computadores podem não ter quaisquer dispositivos que possam utilizar controladores restritos, seja porque todos os dispositivos são totalmente suportados por controladores não restritos ou por não existirem ainda controladores restritos para o dispositivo.

Caso quaisquer controladores se encontrem disponíveis para o seu hardware eles serão instalados a partir da aplicação Software e atualizações:

  • Vá para → Definições → Controladores adicionais

  • Se necessário, ser-lhe-á solicitada a introdução da palavra-passe de administração.

  • Poderá ser-lhe solicitado que reinicie o sistema para concluir a instalação.

Desativação de controladores restritos

Caso um controlador restrito cause problemas, ou caso pretenda apenas desliga-lo, siga o procedimento abaixo:

  • Vá para → Definições → Controladores adicionais

  • Encontre o controlador que pretende desativar e prima o botão Desativar.

  • Ser-lhe-á solicitada a introdução da sua palavra-passe.

Poderá ser necessário reiniciar o computador para concluir a desinstalação do controlador.

Discos e partições

Verificação da quantidade de espaço em disco disponível

Uma maneira simples de verificar o espaço em disco disponível é iniciar o Thunar. Existem várias formas de o fazer:

  • Vá para → Acessórios → Gestor de ficheiros

  • Efetue duplo clique em Sistema de ficheiros ou no ícone do seu Diretório pessoal no ambiente gráfico

  • Clique no diretório pessoal no Painel Lançador

A barra de estado na parte inferior da janela apresenta o espaço livre para a unidade atual ou disco. Caso possua mais do que uma unidade montada ou ligada, pode clicar sobre elas no painel lateral e será apresentado o espaço livre para esse disco.

Como posso libertar espaço em disco?

Existem diversas formas de aumentar o espaço em disco disponível:

  • Esvazie o Lixo clicando com o botão direito do rato no ícone Lixo do ambiente gráfico ou no painel de lançamento e selecionando Esvaziar Lixo.

  • Remover pacotes de software dos quais já não necessita.

  • Elimine ficheiros dos quais já não necessita. Pode instalar o Analisador de Utilização do Disco do GNOME a partir do Software do GNOME para descobrir os ficheiros que se encontram a ocupar mais espaço.

Tenha cuidado para não eliminar ficheiros de que ainda precisa!

Particionar um dispositivo

Pode utilizar oGParted (Editor de Partições do GNOME) para particionar dispositivos de armazenamento. Instale oGParted a partir do Software do GNOME e depois vá para → Gestor de definições → GParted para iniciar o editor de partições.

Tenha cuidado ao alterar partições do disco, já que é possível perder os seus dados caso elimine ou altere a partição errada.

Alterar partições do disco pode demorar algum tempo. Não presuma que o GParted suspendeu ou paralisou enquanto estiver em funcionamento.

Caso seja necessário desmontar o sistema instalado para continuar com as mudanças que pretende efetuar, terá de trabalhar a partir de um CD/USB de instalação para o fazer.

Libertar espaço para uma nova partição

Para criar uma nova partição dentro de um dispositivo já particionado, deve primeiro redimensionar uma partição existente. Caso já possua espaço livre, vá para a secção Criar uma nova partição. Caso contrário, siga as instruções abaixo:

  • Selecione o dispositivo a particionar a partir da lista suspensa no canto superior direito da janela principal

  • Irá aparecer uma lista de partições na janela principal. Selecione a partição que deseja redimensionar e do menu, escolha Partição → Desmontar

  • Para redimensionar a partição escolha Partição → Redimensionar/Mover. A caixa de diálogo Redimensionar/Mover diálogo será mostrada. Pode utilizar a caixa Espaço livre seguinte (MiB) para escolher quanto espaço libertar após esta partição, ou Espaço livre precedente (MiB) para libertar espaço antes desta partição. Alternativamente, pode utilizar o controlo deslizante para ajustar o tamanho da partição.

  • Clique em Redimensionar/Mover

  • Para aplicar as alterações, clique emEditar → Aplicar todas as operações

Criar uma nova partição

Para criar uma nova partição:

  • Selecione o dispositivo a particionar a partir da lista suspensa no canto superior direito da janela principal

  • Aparecerá uma lista de partições. Selecione a que se chama Sem alocação, clique com o botão direito do rato sobre ela e clique em Nova

  • Da lista de seleção Sistema de ficheiros:, escolha o tipo desejado de sistema de ficheiros a utilizar.

  • Caso pretenda, introduza uma descrição para a partição no campo Etiqueta: .

  • Clique no botão Adicionar.

  • Para aplicar as alterações, clique emEditar → Aplicar todas as operações

Formatar uma partição

Para formatar uma partição, faça o seguinte:

  • Selecione o dispositivo a particionar a partir da lista suspensa no canto superior direito da janela principal

  • Aparecerá uma lista de partições. Selecione a partição desejada e escolha Partição → Desmontar.

  • Selecione a partição que deseja formatar e escolha Partição → Formatar para e selecione da lista o tipo de sistema de ficheiros para o qual formatar a partição

  • Para aplicar as alterações, clique emEditar → Aplicar todas as operações

Montar e desmontar dispositivos

Quando ligar um dispositivo de armazenamento removível ao seu computador, ele deve ser montado pelo sistema operativo para que seja capaz de aceder aos ficheiros no dispositivo.

Para saber como montar e desmontar dispositivos de armazenamento manualmente e/ou automaticamente, consulte a página wiki da comunidade Ubuntu para o comando mount.

Quando copia ficheiros para um dispositivo de armazenamento removível, eles nem sempre são escritos no dispositivo imediatamente. Em vez disso, eles são frequentemente armazenados numa fila de modo a que todos possam ser transferidos através do dispositivo ao mesmo tempo (por razões de eficiência). A execução do comando sync pode forçar a gravação de dados pendentes em dispositivos de armazenamento removíveis. Se desligar o dispositivo antes que todos os ficheiros tenham sido transferidos, pode perder os ficheiros. Para o evitar, deve sempre desmontar um dispositivo removível antes de o desligar.

Computadores portáteis

Configurações de Gestão de Energia

Pode desejar alterar as configurações de gestão de energia do seu portátil a fim de ajudar a prolongar a vida da bateria e economizar energia.

  • Vá para → Gestor de definições → Gestor de energia

  • Altere as configurações conforme apropriado

  • As alterações são aplicadas imediatamente

Quando o seu computador portátil se encontrar ligado à bateria, um dos maiores consumidores de energia é o ecrã. Diminuir o brilho do ecrã pode aumentar significativamente a vida da bateria; muitos computadores portáteis permitem fazer isto ao premirFn+F7(ou outras teclas marcadas) várias vezes.

Painéis de toque

A maioria dos computadores portáteis vêm com um painel de toque, que é utilizado para controlar o ponteiro do rato. Há muitas maneiras de alterar a forma como o painel de toque se comporta; as definições mais básicas do painel de toque podem ser configuradas da seguinte forma:

  • Vá para → Definições → Rato e painel de toque

  • Da lista de seleção Dispositivo:, escolha Painel de toque.

  • Aqui pode alterar as configurações do painel de toque ao seu gosto. As mudanças devem entrar em vigor imediatamente.

Alguns painéis de toque podem ser detetados como dispositivos normais de rato, embora sejam realmente painéis de toque. Neste caso, o dispositivo Painel de toque não estará disponível nas preferências do rato. Consulte a página Painéis de Toque na wiki da comunidade Ubuntu para mais informações sobre painéis de toque.

Suspender e Hibernar

De modo a economizar energia, pode colocar o seu computador num dos vários modos de economia de energia quando não estiver a utiliza-lo:

  • Suspender um computador é como colocar o computador a dormir. O computador continuará ligado e todo o seu trabalho será deixado em aberto, mas irá utilizar muito menos energia. Pode ativar o computador premindo uma tecla ou clicando num botão do rato.

  • Hibernar é desligar o computador completamente enquanto guarda o seu estado atual (tal como manter todos os seus documentos abertos). Quando ligar o computador novamente após a hibernação, todo o seu trabalho deverá ser restaurado tal como estava antes da hibernação. Não é consumida energia quando o computador se encontra em hibernação.

  • Retomar é trazer o computador de um modo de economia de energia de volta ao funcionamento normal. Pode retomar o computador do estado de suspensão pelo pressionar de um botão do teclado ou clicando num dos botões do rato. Pode retomar do estado de hibernação premindo o botão de alimentação no computador.

Note que a hibernação se encontra desativada por predefinição no Xubuntu e não aparece como uma opção em quaisquer menus. Para uma solução através da linha de comandos, consulte Ativar a hibernação.

Pode colocar manualmente o seu computador num modo de economia de energia se selecionar → Sair e depois premir o botão apropriado.

Alguns computadores podem ter problemas ao entrar em determinados modos de economia de energia. A melhor maneira de verificar se o seu computador pode lidar com um determinado modo de economia de energia é tentar mudar para esse modo e ver se ele se comporta como o esperado. Certifique-se sempre de guardar documentos importantes antes de suspender ou hibernar.

O meu computador não suspende ou hiberna corretamente

Alguns computadores são incapazes de suspender ou hibernar corretamente com o Xubuntu. Se este for o caso para o seu computador, poderá observar alguns dos seguintes sintomas:

  • O computador não desliga depois de clicar em hibernar.

  • Quando liga o computador após a hibernação, os seus programas anteriormente abertos não são restaurados.

  • O computador não retoma depois de o ter suspendido.

  • Alguns programas ou dispositivos de hardware param de funcionar corretamente após sair do modo de hibernação ou retomar após estar suspenso.

Se sofre de algum destes problemas, deve comunicar o erro no Launchpad. Os problemas serão desejavelmente corrigidos numa versão posterior do Xubuntu. Se o seu hardware não funcionar corretamente após suspender ou hibernar o computador, reinicie-o e deverá voltar ao normal. Caso um programa não funcione adequadamente, tente fecha-o inicia-lo novamente.

Certifique-se de guardar todos os seus documentos abertos antes de testar problemas de suspensão e hibernação.

Ativar a hibernação

Para ativar e utilizar a hibernação com o Xubuntu, faça o seguinte:

  • Instale o pacotepm-utils a partir doSoftware do GNOME.

  • A partir da linha de comando, introduza: sudo pm-hibernate.

  • Introduza a sua palavra-passe.

  • Para retomar a partir do modo de hibernação, prima o botão de energia.

Recebo padrões estranhos no ecrã quando hiberno o meu computador

O seu ecrã poderá apresentar um padrão preto e branco logo após clicar para hibernar o seu computador. Isto geralmente não é nada com que se deva preocupar e é apenas a forma como as placas gráficas de alguns computadores respondem aos estágios iniciais do processo de hibernação. Caso o computador exiba o padrão por um longo período de tempo sem se desligar então poderá ter um problema com a hibernação. Consulte O meu computador não suspende ou hiberna corretamente para mais informações.

Ratos e Teclados

Quando instala o Xubuntu, é-lhe dada a opção de selecionar o seu idioma e disposição do teclado. Durante a instalação, os seus dispositivos apontadores devem ser detetados e configurados automaticamente. Caso pretenda ou deseje alterar as configurações de qualquer um destes dispositivos após a instalação,pode fazê-lo se for ao → Gestor de definições → Rato e painel de toque ou → Definições → Teclado.

As opções para ratos e painéis de toque incluem:

  • Orientação dos botões

  • Velocidade e sensibilidade do ponteiro

  • Sensibilidade do duplo clique

  • Tema do cursor

Algumas das opções para configurar o teclado incluem:

  • Estado da tecla Num Lock ao arrancar

  • Velocidade e atraso de repetição de teclas

  • Velocidade de intermitência do cursor

  • Atalhos de teclado das aplicações

  • Esquema do teclado e idioma

Caso se encontre a utilizar um rato num computador portátil que também possua um painel de toque, pode alterar o comportamento de cada um deles individualmente, selecionando o dispositivo apropriado na lista de seleção Dispositivo: no separador da página Dispositivos.
