Atualizar o Xubuntu

Atualizar o Xubuntu

São lançadas novas versões regulares do Xubuntu a cada 6 meses e versões com suporte de longo prazo (LTS) a cada 2 anos. Atualmente as versões regulares são suportadas por 9 meses e as versões LTS por 3 anos.

As Atualizações de Software irão informa-lo quando uma nova versão para o seu caminho de atualização estiver disponível para transferência. Para alterar o caminho da atualização, consulteAlterar o caminho de atualização.

Habitualmente, as atualizações demoram um pouco a serem concluídas. Normalmente, são transferidos e instalados cerca de 1000 MB de pacotes, embora o número real dependa da quantidade de pacotes já instalada no seu computador.

Atualizar para a próxima versão disponível

  • Vá para o → Gestor de definições → Atualizações de Software e aguarde até que a lista de atualizações seja transferida

  • Se uma nova versão do Xubuntu estiver disponível, uma caixa no topo da janela irá aparecer dizendo que uma nova distribuição está disponível

  • Para atualizar para a próxima versão disponível, guarde todos os seus documentos e clique no botão Atualizar → Gestor de definições → Atualizações de Software

Se não estiver a obter uma notificação de atualização, ou não estiver a ver a versão esperada, ver Alterar o caminho de atualização.

Alterar o caminho de atualização

Existem duas opções de atualização que pode seguir: ou atualizar apenas para versões de suporte de longo prazo (LTS), ou atualizar para todas as versões.

Se decidir optar pelo caminho de atualização LTS, será notificado de novos lançamentos a cada dois anos. Se decidir optar por atualizações de versões regulares, será notificado de novos lançamentos a cada 6 meses. Pode alterar caminho de atualização de regular para LTS assim que tiver atingido a próxima versão LTS.

Se desejar alterar o seu caminho de atualização, pode fazê-lo quando estiver a executar uma versão LTS. Para isso, escolha uma das seguintes opções:

  • Navegue para → Software → Software e Atualizações e selecione o separador Atualizações. No separador Atualizações, selecione Para qualquer versão ou Para versões com suporte a longo prazo da lista expansível Notificar-me de uma nova versão do Ubuntu, dependendo da sua escolha.

  • Abra o → Acessórios → Emulador de terminal, execute sudo edit /etc/update-manager/release-upgrades e altere a linha que começa com prompt= para prompt=normal (para todas as versões) ou prompt=lts (para versões LTS), dependendo da sua escolha

Se estiver a executar uma versão regular que não seja imediatamente seguida de uma versão LTS, não deve alterar o destino de atualização para versões de suporte de longo prazo (LTS) apenas.

Atualizar uma versão LTS para algo diferente de uma outra versão LTS perderá o suporte de longo prazo.

Atualizar para a versão de desenvolvimento

Versões de desenvolvimento sofrem muitas vezes de ruturas de pacotes e outros problemas. Só instale uma versão de desenvolvimento se estiver preparado para tentar corrigir esses problemas para si mesmo ou se quiser ajudar a equipa Xubuntu, testando e dando feedback.

Necessitará de estar a executar a versão regular mais recente para ser capaz de atualizar para a versão atualmente em desenvolvimento.

Se deseja instalar e testar a última versão de desenvolvimento do Xubuntu antes que seja lançada, execute update-manager -c -d na linha de comandos. Isto irá permitir que atualize para a versão de desenvolvimento atual. Por favor, considere envolver-se e reportar o uso de versões de desenvolvimento e pacotes associados.

Notificações de novas versões do Xubuntu

Esta secção das Atualizações de Software lida com a forma como deseja que versões futuras lhe sejam oferecidas. Existem três opções:

  • Para qualquer versão nova - Será notificado de todas as novas versões, de 6 em 6 meses.

  • Para versões de suporte a longo prazo - Será notificado de novas versões de suporte a longo prazo (LTS), de 2 em 2 anos.

  • Nunca - Não será notificado de novas versões.

Optar por notificações para versões de suporte de longo prazo (LTS) é geralmente a opção recomendada, especialmente se estiver a executar o Xubuntu numa máquina produção e/ou precisar de estabilidade máxima.

Não é recomendado utilizar a definição Nunca. A menos que se lembre de atualizar manualmente com frequência, isto irá deixa-lo com um sistema sem suporte. Além disso, não receberá correções de erros, atualizações a potenciais problemas de segurança e melhorias no suporte a hardware.
